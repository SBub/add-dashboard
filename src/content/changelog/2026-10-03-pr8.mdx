The first production release. A project page reads its runs from the database, updates live as runs start and finish, and moves finished runs into a History section rendered on the server.

## Features

- Project pages load their runs on the server and show them on first paint, with no second request from the browser ([PR #1](https://github.com/SBub/adw-dashboard/pull/1))
- Runs come from the database instead of sample data ([PR #2](https://github.com/SBub/adw-dashboard/pull/2))
- Runs update live: new and finished runs appear without a reload, and the sidebar counts follow them ([PR #4](https://github.com/SBub/adw-dashboard/pull/4))
- Completed runs move into a History section rendered on the server; running and failed runs stay live above it ([PR #6](https://github.com/SBub/adw-dashboard/pull/6))
- History refreshes when a run completes, even if nobody has the page open, through a database webhook ([PR #7](https://github.com/SBub/adw-dashboard/pull/7))

## Chores

- Removed the "updated X ago" label, the stale badge and the running timer until they can be shown without a ticking clock ([PR #5](https://github.com/SBub/adw-dashboard/pull/5))
