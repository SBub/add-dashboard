History cards now show what each run cost and link its pull request. The sidebar shows whether the build worker is online, and each day in the summary has a third chart: cost by phase. Pages show grey placeholders while they load, and the header stays in view as you scroll.

## Features

- Each day in the summary gets a third chart, cost by phase: plan, build, test, review and document ([#125](https://github.com/SBub/adw-dashboard/issues/125), [PR #126](https://github.com/SBub/adw-dashboard/pull/126))
- Project pages show grey placeholder shapes while data loads, so nothing jumps when it arrives ([#128](https://github.com/SBub/adw-dashboard/issues/128), [PR #130](https://github.com/SBub/adw-dashboard/pull/130))
- History cards show what each run cost ([#146](https://github.com/SBub/adw-dashboard/issues/146), [PR #154](https://github.com/SBub/adw-dashboard/pull/154))
- History cards link the run's pull request ([#147](https://github.com/SBub/adw-dashboard/issues/147), [PR #160](https://github.com/SBub/adw-dashboard/pull/160))
- The sidebar shows whether the build worker is online, read from its heartbeat ([#158](https://github.com/SBub/adw-dashboard/issues/158), [PR #162](https://github.com/SBub/adw-dashboard/pull/162))

## Fixes

- The whole app uses one background colour, in light and dark mode, even below a short page ([#122](https://github.com/SBub/adw-dashboard/issues/122), [PR #124](https://github.com/SBub/adw-dashboard/pull/124))
- Columns in the day charts are evenly spaced, however long their labels ([#131](https://github.com/SBub/adw-dashboard/issues/131), [PR #132](https://github.com/SBub/adw-dashboard/pull/132))
- Turning a History page keeps your scroll position and dims the list while the next page loads ([#148](https://github.com/SBub/adw-dashboard/issues/148), [PR #155](https://github.com/SBub/adw-dashboard/pull/155))
- A run between two phases shows the last one as done (for example "Build done") instead of "Complete" ([#152](https://github.com/SBub/adw-dashboard/issues/152), [PR #157](https://github.com/SBub/adw-dashboard/pull/157))
- History is ordered by when each run finished, so a later edit to a run no longer reshuffles the list ([#153](https://github.com/SBub/adw-dashboard/issues/153), [PR #161](https://github.com/SBub/adw-dashboard/pull/161))

## Chores

- Removed the coloured dot before each chart title; it meant nothing ([#119](https://github.com/SBub/adw-dashboard/issues/119), [PR #121](https://github.com/SBub/adw-dashboard/pull/121))
- The Queue follows a column rename in the toolkit's database; nothing changes on screen ([#120](https://github.com/SBub/adw-dashboard/issues/120), [PR #123](https://github.com/SBub/adw-dashboard/pull/123))
- Moved the feature descriptions out of the README into one doc per feature ([#127](https://github.com/SBub/adw-dashboard/issues/127), [PR #133](https://github.com/SBub/adw-dashboard/pull/133))
- Removed the halted count from the summary; the toolkit no longer records it ([#134](https://github.com/SBub/adw-dashboard/issues/134), [PR #136](https://github.com/SBub/adw-dashboard/pull/136))
- The Active explanations no longer promise a resume button that does not exist yet ([#135](https://github.com/SBub/adw-dashboard/issues/135), [PR #138](https://github.com/SBub/adw-dashboard/pull/138))
- Queue rows drop the manual hint and the queued time, and the title gets the full width ([#137](https://github.com/SBub/adw-dashboard/issues/137), [PR #139](https://github.com/SBub/adw-dashboard/pull/139))
- The header stays at the top while the page scrolls under it ([#141](https://github.com/SBub/adw-dashboard/issues/141), [PR #143](https://github.com/SBub/adw-dashboard/pull/143))
- Run rows show the phase as a word like "Building" instead of a step key like `adw_build_iso` ([#142](https://github.com/SBub/adw-dashboard/issues/142), [PR #144](https://github.com/SBub/adw-dashboard/pull/144))
- History cards drop the repeated status, final phase and start time, and show the full branch name, linked to GitHub ([#145](https://github.com/SBub/adw-dashboard/issues/145), [PR #150](https://github.com/SBub/adw-dashboard/pull/150))
- TypeScript and ESLint skip the pipeline's worktrees, so a run in progress can no longer break the main build ([#151](https://github.com/SBub/adw-dashboard/issues/151), [PR #156](https://github.com/SBub/adw-dashboard/pull/156))
