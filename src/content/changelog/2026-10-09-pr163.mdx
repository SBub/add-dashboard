Promotes `develop` to production (`master`): 85 commits, 20 merged PRs (#121 to #162).

Production is currently broken: the database migration that dropped `adw.daily_summary.halted` is applied, and master still selects that column, so both summary islands on `/` (today and past days) fail. This release includes #134 (halted removed from the summary), which fixes it.

## Features

- Day card: third chart, cost by phase ([#125](https://github.com/SBub/adw-dashboard/issues/125), [PR #126](https://github.com/SBub/adw-dashboard/pull/126))
- Projects pages: skeleton fallbacks for every Suspense boundary ([#128](https://github.com/SBub/adw-dashboard/issues/128), [PR #130](https://github.com/SBub/adw-dashboard/pull/130))
- History card: show the cost of each run ([#146](https://github.com/SBub/adw-dashboard/issues/146), [PR #154](https://github.com/SBub/adw-dashboard/pull/154))
- History card: link the run's pull request ([#147](https://github.com/SBub/adw-dashboard/issues/147), [PR #160](https://github.com/SBub/adw-dashboard/pull/160))
- Sidebar: worker status widget (online/offline from the heartbeat) ([#158](https://github.com/SBub/adw-dashboard/issues/158), [PR #162](https://github.com/SBub/adw-dashboard/pull/162))
