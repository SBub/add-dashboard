First production release of the ADW dashboard.

Includes everything merged into develop so far: projects sidebar and per-project runs prefetched on the server and hydrated, database reads with the publishable key, Realtime for projects and runs with live sidebar counts and catch-up on subscribe, server-rendered completed history as a request-time hole with revalidation from the browser and from the database webhook, the connection indicator, and the Yarn 4.18.1 and corepack fixes for the Vercel build.

Production tracks master on Vercel at https://adw-dashboard.vercel.app. The database webhook in the toolkit already points at that host and becomes effective with this deployment.

## Features

- prefetch and hydrate a project's runs, one file for query keys ([PR #1](https://github.com/SBub/adw-dashboard/pull/1))
- read a project's runs from the database and derive run labels from a client clock ([PR #2](https://github.com/SBub/adw-dashboard/pull/2))
- realtime runs listener, live sidebar counts and catch-up on subscribe ([PR #4](https://github.com/SBub/adw-dashboard/pull/4))
- server-render completed runs as history, keep running and failed live ([PR #6](https://github.com/SBub/adw-dashboard/pull/6))
- revalidate a project's history from a database webhook ([PR #7](https://github.com/SBub/adw-dashboard/pull/7))

## Chores
